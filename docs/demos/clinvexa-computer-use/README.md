# CLINVEXA Computer Use 医疗演示案例

## 案例：复诊病历草稿自动录入模拟 HIS

一名呼吸道症状复诊患者带来脱敏病情摘要和检查结果。医生让 CLINVEXA 读取材料、整理病历字段，再通过 Computer Use 操作模拟 HIS，把内容填写为“病历草稿”。CLINVEXA 保存草稿后停止，不提交正式病历，由医生现场核对。

这个案例适合向医疗工作者展示以下能力：

1. 读取并理解脱敏医疗材料。
2. 将非结构化描述整理为主诉、现病史、检查摘要、初步诊断和处置计划。
3. 首次截图识别桌面中的 HIS 窗口、患者编号和可交互控件。
4. 优先使用可访问控件编号填写；不可用时才使用带截图证据的坐标回退。
5. 每写入一个字段都重新捕获页面，核对窗口、患者和可读取的字段值。
6. 只保存草稿，不提交正式病历，保留医生最终确认环节。

## 演示材料

- `01-患者材料-脱敏.txt`：Computer Use 任务的输入材料。
- `02-模拟HIS-门诊复诊.html`：完全离线、无真实患者数据的模拟 HIS 页面。
- `03-CLINVEXA演示指令.txt`：可直接复制到 CLINVEXA 主对话框的任务指令。
- `04-演示核对单.md`：演示人员用于判定执行是否成功的核对表。

## 演示前准备

1. 在 CLINVEXA 的“技能与工具”中确认 Computer Use 已启用且状态为“就绪”。
2. 双击打开 `02-模拟HIS-门诊复诊.html`，建议使用 Chrome 或 Edge。
3. 保持模拟 HIS 页面窗口打开，不要手工填写任何字段。
4. 在 CLINVEXA 中新建会话，选择“桌面与 HIS Agent”。
5. 把 `03-CLINVEXA演示指令.txt` 的全部内容复制到主对话框并发送。

## 推荐现场讲解流程

1. 展示患者材料，说明所有数据均为虚构脱敏数据。
2. 发送演示指令，让 CLINVEXA 先说明将要填写的字段。
3. 观察 CLINVEXA 首次捕获窗口并核对患者编号 `DC-DEMO-0001`。
4. 观察主诉、现病史、检查摘要、初步诊断、处置计划、随访计划逐项写入；每项后均重新捕获验证。
5. 观察页面右上角状态从“未填写”变为“草稿已保存”。
6. 对照核对单检查六个字段，并强调“提交正式病历”仍保持禁用。

## CLINVEXA 实际工作流

`能力与边界检查 → 打开/聚焦材料和 HIS → 基线截图 → 核对窗口/患者/弹窗 → 读取来源证据 → 建立证据到字段映射 → 写入前二次核验 → 逐字段写入并回读 → 保存前总复核 → 保存草稿 → 保存后状态验证 → 简体中文审计报告`

每一步最多重试一次。任何一步出现窗口变化、患者不一致、遮挡弹窗、字段缺失、来源证据不足、写入后无法回读或保存状态无法验证，CLINVEXA 都会停止，不会继续点击保存或提交；窗口恢复后必须重新从基线核验开始。

## 预计时长

完整演示约 3～5 分钟。首次启动 Computer Use 时，驱动初始化可能额外需要约 30 秒。

## 演示边界

- 本案例只操作本地模拟 HIS，不连接真实医院系统。
- 不使用真实姓名、证件号、手机号或真实诊疗数据。
- CLINVEXA 生成的是辅助草稿，不替代医生诊断。
- 不演示自动开医嘱、自动处方或自动提交正式病历。
