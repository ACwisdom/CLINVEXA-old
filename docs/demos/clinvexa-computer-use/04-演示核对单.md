# CLINVEXA Computer Use 演示核对单

## 功能核对

- [ ] CLINVEXA 能读取指定患者材料。
- [ ] CLINVEXA 能找到标题包含“CLINVEXA 模拟 HIS”的浏览器窗口。
- [ ] 执行过程中真实鼠标仍可由演示人员正常移动。
- [ ] 主诉填写为咳嗽、低热相关内容。
- [ ] 现病史包含病程 3 天、最高体温 37.8℃、无胸痛和无明显气促。
- [ ] 检查摘要包含体温、血氧、白细胞、C 反应蛋白和流感抗原结果。
- [ ] 初步诊断明确标记“待医生确认”。
- [ ] 处置计划没有生成材料之外的药品、剂量或医嘱。
- [ ] 随访计划为 3 天后复诊，症状加重则提前复诊。
- [ ] 页面最终显示“草稿已保存”。
- [ ] “提交正式病历”未被点击且仍保持禁用。
- [ ] CLINVEXA 最终以简体中文汇报执行结果。

## 成功标准

以上 12 项全部满足，视为该 Computer Use 演示闭环通过。

## 常见问题

- 找不到窗口：确认模拟 HIS 页面已打开，浏览器窗口标题中能看到“CLINVEXA 模拟 HIS”。
- 无法点击或输入：在 CLINVEXA 的 Computer Use 设置中运行状态检查。
- 元素编号失效：让 CLINVEXA 重新 capture 后再操作，不要复用旧编号。
- 页面已填写但状态未变化：要求 CLINVEXA 重新识别页面并点击“保存病历草稿”。
