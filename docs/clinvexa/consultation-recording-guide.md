# CLINVEXA 问诊记录使用说明

## 功能定位

本功能用于医生与患者问诊期间持续记录语音，在问诊结束后自动生成简体中文转写和待医生复核的病历草稿。它不会替代医生判断，也不会自动提交正式病历。

## 使用流程

1. 打开 CLINVEXA 侧边栏，点击“开始问诊记录”。
2. 填写患者编号；患者姓名可选。
3. 在已取得患者同意后，勾选“患者已知情并同意本次问诊记录”。
4. 点击“开始问诊记录”。只有执行到这一步，CLINVEXA 才会申请麦克风权限并开始录音。
5. 问诊过程中可暂停或继续录音，也可点击主诉、现病史、既往史、过敏史、用药史、检查信息、初步判断、诊疗计划或重点内容进行标记。标记不会中断录音。
6. 点击“结束问诊并生成草稿”，等待本地语音服务完成简体中文转写和病历字段整理。
7. 查看完整转写、病历草稿和待复核项。可复制草稿，或交给病历 Agent 使用 `$outpatient-note-draft` Skill 深度整理。

## 使用边界

- 打开 CLINVEXA 或打开问诊面板不会自动录音。
- 未填写患者编号或未勾选知情确认时，不能开始录音。
- 转写、重点标记和病历草稿均绑定本次患者编号保存。
- 所有草稿均标记为需要医生复核，不自动写入或提交正式病历。
