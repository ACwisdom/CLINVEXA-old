# CLINVEXA 用户安装与使用指南

## 1. 安装与启动

### 系统要求

- Windows 10 22H2 或 Windows 11，64 位。
- 至少 16 GB 内存、10 GB 可用磁盘空间；推荐 32 GB 内存、20 GB 可用空间。
- 麦克风（使用中文语音输入或问诊记录时需要）。
- 如使用云模型，需要能够访问所选模型提供方的 HTTPS 接口。

### 安装步骤

1. 双击唯一正式安装包 `CLINVEXA-0.17.2-win-x64.exe`。
2. 按安装向导选择目录并完成安装。无需单独安装 Python、Node.js、语音模型或 Computer Use 驱动。
3. 双击桌面上的 **CLINVEXA** 图标。
4. 首次启动会自动释放本地运行时并启动 Agent 网关、医疗 Skill 服务、中文语音服务和 Computer Use 驱动。首次初始化耗时取决于磁盘速度，完成后自动进入 CLINVEXA Agent。
5. 后续启动只需双击图标；程序会自动检查并恢复所需服务。

0.17.2 起安装程序固定使用 `%LOCALAPPDATA%\Programs\CLINVEXA`，不会继承旧测试版或临时目录。升级后桌面快捷方式始终指向这一唯一正式入口。

不要从源码子目录、历史缓存或 `win-unpacked` 的旧副本启动。正式交付只认安装后的桌面快捷方式。

## 2. 配置模型

CLINVEXA 支持 OpenAI-compatible 自定义端点，不在源码或安装包内保存用户 API Key。

1. 打开 **设置 → 提供方/模型 → 自定义端点**。
2. 新建提供方并填写：
   - 名称：便于识别的名称，如“院内模型”或“阿里云百炼”。
   - Base URL：提供方给出的 OpenAI-compatible 地址，通常以 `/v1` 结尾。
   - API Key：在本机设置界面保存，不要写入共享文档或源码。
   - 模型 ID：必须与提供方返回的模型标识完全一致。
3. 点击连接测试或模型发现；成功后选择该模型并点击“应用”。
4. 新建会话，发送“你是谁？你能做什么？”验证。正常回答应以 CLINVEXA 医疗 AI 办公助手身份、简体中文输出。

模型至少应支持流式文本；需要 Agent 自动操作时，应支持稳定的工具调用。使用屏幕图片、影像截图或图表理解时，应配置具备视觉能力的模型。

CLINVEXA 会探测自定义端点报告的上下文长度并缓存有效结果；每次请求依据实际上下文、输入估算和安全余量动态计算输出 token 预算。探测失败时，自定义端点按 64K 保守值运行，不会误按 256K 发送超限请求。

## 3. 常用功能

### 医疗问诊记录

1. 打开 CLINVEXA，点击“开始问诊记录”后才会开始录音。
2. 问诊中可标记重点；系统只保留简体中文转写。
3. 结束记录后自动生成九字段病历草稿：主诉、现病史、既往史、过敏史、用药史、检查检验信息、初步判断、处置建议、随访计划。
4. 对话未涉及的字段显示“对话未涉及，待医生补充”，不会复制整段问诊内容填充所有字段。
5. 点击“交给病历 Agent 深度整理”会创建一个新会话并在左侧会话列表中显示，再执行深度整理。

### Skill 与多 Agent

- 在“技能与工具”中可按“医疗/办公事务”分类浏览，并在简体中文与 English 间切换介绍语言。
- 在 Skill 广场中搜索、安装、启用、禁用、卸载和运行医疗 Skill。
- “自动选择”由主控 Agent 判断任务；也可手动选择病历 Agent、知识与患者管理 Agent、桌面与 HIS Agent。
- `skill-creator` 用于创建、校验并发布新 Skill；发布成功后可在 Skill 广场检索和调用。

### 文件与预览

- 可上传 Word、Excel、PDF、图片、文本等材料。
- Word/Excel 使用结构化预览，PDF 使用 PDF 渲染，不再按二进制文本显示乱码。
- 医疗结果必须保留来源证据；正式病历、诊断、处方、医嘱和患者发送内容仍由医生复核。

### Computer Use 与 HIS RPA

- CLINVEXA 可截图分析当前界面、识别可访问控件、打开应用、点击、输入和验证操作结果。
- 普通界面操作按已授权的高访问模式执行；上传文件、向外发送文件等跨边界操作仍要求明确确认，危险删除快捷键和危险命令被硬阻断。
- HIS 流程为：识别窗口和患者 → 读取/截图分析 → 填写草稿 → 校验字段与页面状态 → 医生确认 → 保存或提交。
- 页面变化、患者不匹配、弹窗遮挡或控件不存在时应立即停止，不能虚构成功。

## 4. 故障处理

- **模型连接失败**：检查 Base URL 是否含 `/v1`、模型 ID 是否正确、API Key 是否有效、网络是否能访问提供方。
- **Skill 广场不可用**：等待启动完成；CLINVEXA 会自动拉起 8001 医疗服务并健康检查。仍失败时完全退出后重新双击桌面图标。
- **语音无结果**：确认 Windows 麦克风权限、选中正确输入设备，并重新点击语音按钮。问诊录音必须先点击“开始问诊记录”。
- **Computer Use 无法定位**：先将目标窗口显示在桌面并保持未最小化；复杂页面会先截图/读取 UI Automation 后再执行。
- **日志位置**：`%APPDATA%\CLINVEXA\runtime\logs\desktop.log`。日志中可能包含文件路径和任务信息，外发前请脱敏。
- **Windows 提示未知发布者**：当前验收安装包尚未使用组织代码签名证书，Windows 可能显示 SmartScreen 提示。院内正式分发前应完成安装包代码签名和发布者验证。

## 5. 数据与安全提醒

- CLINVEXA 是医疗办公辅助工具，不替代医生的诊断、处方和治疗决策。
- 使用真实患者信息前应遵循医院的数据授权、网络、日志、备份和留存制度。
- API Key 只在用户本机配置，禁止写入源码、安装包、聊天截图或共享文档。
- 正式保存病历、提交 HIS、发送患者消息或上传文件前，必须核对患者身份、目标系统和内容。
