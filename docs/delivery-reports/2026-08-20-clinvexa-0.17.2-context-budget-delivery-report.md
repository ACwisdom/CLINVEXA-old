## 本次修复

1. 自定义 OpenAI-compatible 端点的模型元数据探测支持瞬时超时、连接失败和 HTTP 5xx 重试；瞬时失败不写入空缓存，成功探测结果持久化。
2. 远程自定义端点（包括 N260/LAN）无法确认上下文时使用 64K 保守值，不再误套用 256K 全局默认值；本机回环/容器宿主端点保留原 256K 本地回退。端点一旦报告真实上下文，始终优先使用真实值。
3. 首次模型请求前依据实际上下文、输入 token 估算、安全余量及用户显式上限动态计算 `max_tokens`，并清理相互冲突的输出 token 参数。
4. 安装器固定使用 `%LOCALAPPDATA%\Programs\CLINVEXA`，禁止继承旧版临时/开发目录；构建脚本会硬性检查该约束。

- `GET /v1/models` 连续两次成功，模型 `/workspace/model`，报告上下文 `65536`，耗时约 509 ms 与 80 ms。
- 64 token 的短请求返回 `finish_reason=length` 且正文为空，说明推理 token 会消耗过小的输出预算。
