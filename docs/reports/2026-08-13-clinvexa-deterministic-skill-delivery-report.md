## 交付范围

- 病历结构化：导入一个或多个文件、或一个文件夹后，在 Skill 广场运行；本地固定脚本递归读取资料，生成一个汇总 Excel 和一个工作表。
- 门诊病历草稿：本地固定脚本可识别字段标签、标题区块和医患问答，按九字段独立提取，自动生成 UTF-8 BOM TXT。
- 随访计划：本地固定脚本可识别标题区块和明确随访要求，提取时间、方式、观察项、复查项、异常触发条件与患者限制，自动生成一个 UTF-8 BOM TXT。
- TXT 读取：允许 UTF-8 中文在 1000 字节截断边界出现的单个替换符，避免被误判为二进制；真实二进制特征仍会被拦截。

## 固定工作流

1. 用户在 CLINVEXA 主对话框导入文件或文件夹。
2. 用户打开 Skill 广场，选择已安装且已启用的目标 Skill，点击“运行”。
3. 桌面端把当前附件的绝对路径交给 `127.0.0.1:8001` 的 CLINVEXA 本地服务。
4. 核心医疗 Skill 由 `clinvexa.deterministic_skills` 直接执行，不调用模型端点，不生成临时 PowerShell/Python，不改变交付格式。
5. CLINVEXA 主对话框通过 NDJSON 流依次显示资料接收、文件读取、字段提取、规则校验和结果生成；每条进度均由真实脚本阶段触发，并以“处理过程”分项列表持续保留在对话中。
6. 字段提取阶段显示来源文件、识别到的文档结构、已提取字段及待补字段；规则校验阶段按实际结果显示“完整提取”或具体缺失项。
7. 脚本验证输出文件存在且非空后，在主对话框显示结构化结果摘要、医生复核提示和完整绝对路径；Skill 广场不再显示单行“执行完成”。

## 确定性与医疗边界

- 只映射原文明确字段、标题区块、医患问答和医生明确结论，不使用模型补写事实。
- 未提及内容固定标为“原文未涉及，待医生补充”“对话未涉及，待医生补充”或“待医生确定”。
- 不新增诊断、药物、检查、处置或随访事项。
- 所有产物标记 `requires_human_review: true`，保留来源路径、来源证据和免责声明。
- 其他非核心办公 Skill 仍沿用原有 Agent 执行方式，避免影响现有通用能力。
