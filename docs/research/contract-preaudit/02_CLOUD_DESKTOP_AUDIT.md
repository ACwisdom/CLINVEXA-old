| 访问方式 | 深信服 aDesk 独享桌面，Windows 本机可枚举远端会话窗口。本轮窗口最小化，恢复后两次捕获超时，只得到窗格和水印控件，未进入 OA 页面 | 已验证，本轮 Computer Use |
| OS、磁盘 | 用户此前在远端 PowerShell 查询 Windows 10 企业版 LTSC x64，Build 17763。11-12 08:55 截图显示 C 盘 79.4 GB、可用 56.1 GB，D 盘 19.9 GB、可用 862 MB。O/P 分别是当时映射的本机 C/D | 已验证，历史用户截图。余量和映射会随会话变化 |
| 软件及工具 | 用户截图可见 Chrome、PowerShell、资源管理器、项目目录。其他 AI 客户端、Office、OCR 引擎和管理员权限未知 | 已验证或未知，按项区分 |
| 安装和文件权限 | 通用 Build 19045 门槛包此前被拒。Build 17763 兼容完整包已通过映射盘复制到远端 C 盘并做 SHA256 校验。可见路径为 `C:\Users\rjuser\AppData\Local\CLINVEXA-Install` | 已验证，历史截图。写入 C 用户目录成功，CLINVEXA 远端安装/启动仍未知 |
| 网络 | 院内 OA 在用户云桌面 Chrome 可打开。本轮从本机对院内 OA 端口探测超时。远端能否到院内模型、独立应用服务器，及相应认证、出入站策略未知 | 已验证或未知，按项区分 |

本轮未打开真实合同、下载 OA 附件、提交或修改记录。确认 OA 里对应的 2234 项目和完整流程，需要有权限的测试记录、脱敏表单与附件区、流程图和实际审批轨迹。建议院方确认前置招采审批与业务合同的关联键。
