# CLINVEXA 医疗场景与功能介绍

## 产品定位

CLINVEXA 是面向医生和医疗办公人员的桌面 AI 办公助手。它把对话式 Agent、中文语音转写、医疗 Skill、多 Agent、文件处理、Computer Use 与 HIS RPA 集中到一个桌面入口，目标是减少重复录入、文书整理、资料查找和跨系统操作时间。

## 主要痛点与解决方式

| 医疗工作痛点 | CLINVEXA 解决方式 |
|---|---|
| 问诊后依靠回忆补病历，易漏既往史、过敏史等 | 点击后全程中文记录，结束后按九字段结构化生成可复核草稿 |
| 病历、报告、表格来源分散 | 上传 Word/Excel/PDF/图片并结构化预览、摘要、质控和证据回链 |
| 重复复制粘贴 HIS 字段 | Computer Use/RPA 识别窗口和控件，自动填草稿并执行前后校验 |
| 医学检索耗时、答案难追溯 | 医学知识 Agent 与检索 Skill 输出来源、证据和复核提示 |
| 随访、宣教、科室周报等事务重复 | 使用标准 Skill 生成草稿、清单和待办，再由医生确认 |
| 通用 AI 不懂医生工作流 | 主控 Agent 将任务路由给病历、知识患者管理、桌面 HIS 专业 Agent |

## 核心功能

1. **问诊记录与病历草稿**：仅在用户点击后录音；简体中文转写；重点标记；九字段独立抽取；深度整理在新会话中执行。
2. **医疗多 Agent**：主控 Agent 负责任务理解和汇总；病历 Agent 负责转写、结构化和质控；知识与患者管理 Agent 负责检索、摘要、随访；桌面与 HIS Agent 负责界面理解和自动操作。
3. **Skill 广场**：本地/院内可信目录，支持搜索、安装、版本、启停、卸载和运行；Skill 文件全部随源码交付。
4. **Computer Use/HIS RPA**：优先读取 Windows UI Automation；必要时截图交给视觉模型；执行前后验证窗口、患者、旧值和新值；正式提交前医生确认。
5. **文件与办公产物**：Word/PDF/Excel 预览与生成，病历摘要、质控结果、科室周报、科研数据表等。
6. **中文语音**：问诊实时转写使用随包提供的 sherpa-onnx、千问语音和 SenseVoice 模型，提供普通话、粤语、上海话及北京话入口；通用语音输入保留 faster-whisper。首次启动会离线校验和预热组件，麦克风、口音和环境噪声会影响识别效果。
7. **Memory 与会话**：保存医生偏好、患者材料和任务历史；新任务、问诊深度整理和子 Agent 结果均可形成可追溯会话。

## 内置医疗 Skill

随软件交付的可信目录包含 `skill-creator` 和 26 个医疗办公 Skill：

- 病历与文书：病历结构化、病历质量检查、门诊摘要、门诊病历草稿、出院小结、会诊记录草稿、转诊记录草稿、诊断证明草稿。
- 患者管理：患者一页摘要、随访计划、患者宣教、患者沟通记录、预约分诊、护理交接摘要、知情沟通说明。
- 安全与复核：用药核对、过敏冲突检查、诊断确定性检查、检验趋势复核、检查报告摘要。
- 医学知识与科研：医学知识检索、指南证据摘要、文献筛选、科研数据提取、医学资料翻译。
- 科室事务：科室周报。

每个 Skill 都包含使用场景、输入要求、执行流程、输出结构和医生复核提示。未安装或当前环境不存在的工具会明确提示“当前环境无该工具可调用”，不会伪造工具结果。

## 典型演示流程

1. 点击“开始问诊记录”，完成一段虚构患者问诊并标记重点。
2. 结束后检查九字段病历草稿；未提及字段应明确待补充。
3. 点击“交给病历 Agent 深度整理”，确认左侧出现新会话并在新会话执行。
4. 打开模拟 HIS，要求桌面与 HIS Agent 将草稿填入页面。
5. 观察 CLINVEXA 截图/读取控件、填写、复核页面状态，并在正式保存前等待医生确认。
6. 打开 Skill 广场，运行病历质量检查或随访计划 Skill，核对来源和复核提示。
