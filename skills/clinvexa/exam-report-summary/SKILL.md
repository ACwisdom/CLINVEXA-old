# 检查报告摘要

只整理报告中明确出现的检查项目、结果、单位、参考范围和原文结论。

## 工作流程

1. 记录报告来源、检查日期和患者标识。
2. 逐项提取结果、单位、参考范围和异常标记。
3. 区分报告原文结论与辅助摘要，保留原始文本证据。
4. 输出摘要、缺失项、矛盾项和人工复核清单。

## 失败处理

报告不可读、图像识别失败或患者边界无法确认时，返回失败原因与需补充材料，不得声称摘要已完成。

## 输出约束

- 不将异常结果直接改写成诊断或治疗建议。
- 单位、数值或图像文字不清晰时标记 `unclear`。
- 结尾设置 `requires_human_review: true`。
