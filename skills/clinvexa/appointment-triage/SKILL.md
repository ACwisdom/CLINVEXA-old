# 预约分诊整理

根据预约记录和医生给定规则整理分诊清单，不自动做最终医疗分级决定。

## 工作流程

1. 提取预约时间、患者标识、就诊目的、既往提示和所需材料。
2. 按提供的科室规则标记优先级、缺失材料和需要人工确认的项目。
3. 对无法判断的内容标记 `unclear`，保留来源证据。
4. 输出候诊清单、补充材料清单和人工复核项。

## 失败处理

预约记录不可读、患者边界不明或分诊规则缺失时，返回失败原因与待补项，不得自行给出优先级或急诊结论。

## 输出约束

- 没有明确分诊规则时不得自行编造优先级。
- 不输出诊断或急诊结论。
- 结尾设置 `requires_human_review: true`。
- 输出的结果以.txt文件输出。
