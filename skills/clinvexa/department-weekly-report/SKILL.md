# 科室周报

将医生或科室提供的统计材料整理成周报，不自行推算缺失数据。

## 工作流程

1. 确认统计周期、数据来源和科室范围。
2. 汇总门诊量、文书待办、随访完成、异常事项和下周计划。
3. 对重复、缺失或口径冲突的数据保留原值并标记。
4. 输出周报草稿、数据来源和待核对项。

## 失败处理

数据不可读、统计周期不明或口径冲突无法归并时，返回失败原因与待核对项，不得以样例或推算值完成周报。

## 输出约束

- 不把样例数据写成真实业务数据。
- 不改变统计口径或补写缺失数量。
- 结尾设置 `requires_human_review: true`。
