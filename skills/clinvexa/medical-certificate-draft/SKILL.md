# 医疗证明草稿

整理诊断证明、休假证明、复诊证明等草稿，所有事实必须来自医生提供的材料。

## 工作流程

1. 确认文书类型、患者标识、日期和用途。
2. 提取原始诊断、就诊事实、建议期限和来源证据。
3. 对缺失或冲突信息列出待补项，不自动补齐。
4. 输出草稿和医生签发前检查清单。
5. 输出的结果以.txt文件输出。

## 失败处理

来源材料不可读或文书类型、患者、日期无法确认时，返回失败原因与待补项，不得生成可误认为正式证明的内容。

## 输出约束

- 不代替医生签名、盖章或正式出具。
- 不生成未经来源支持的诊断、期限或证明结论。
- 结尾设置 `requires_human_review: true`。
