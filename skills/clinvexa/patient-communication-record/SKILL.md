# 患者沟通记录

把录音转写、聊天或电话摘要整理为可追溯的沟通记录。

## 工作流程

1. 区分患者、家属、医生和其他发言人；身份不明时标记 `unclear`。
2. 提取患者问题、医生已说明内容、患者反馈和后续待办。
3. 提取精确的医疗问题，理清楚医生和患者的对话内容。
4. 为关键结论保留原话或来源编号，标出听写不清和冲突内容。
5. 输出沟通记录、待办清单和人工复核项。

## 失败处理

录音、转写或聊天记录不可读，或发言人边界无法确认时，返回失败原因与待补材料，不得拼接或猜测沟通结论。

## 输出约束

- 不把沟通内容改写成新的诊断、处方或承诺。
- 不自动发送消息；发送前由医生确认。
- 结尾设置 `requires_human_review: true`。
