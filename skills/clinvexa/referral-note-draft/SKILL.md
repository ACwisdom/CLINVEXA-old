# 转诊记录草稿

只处理输入材料、医生明确提供的信息和真实工具结果。

## 工作流程

1. 确认输入范围、来源编号、文书类型和任务目标。
2. 整理转诊原因、已知病情、检查、用药、过敏和待处理事项。
3. 为关键事实保留来源编号和原始文本；数值同时保留原始单位与标记。
4. 区分 present、absent、not_mentioned、suspected、ruled_out、unclear 和 conflict。
5. 输出草稿或检查清单、来源证据、缺项冲突和人工复核项。

## 输出约束

- 不编造患者身份、时间、诊断、药物、检查、来源或随访事项。
- 不自动修正冲突、OCR 模糊内容、剂量单位或诊断确定性。
- 没有可靠来源时明确写明“依据不足”；所需工具未加载时返回“当前环境无该工具可调用”。
- 所有医疗结果设置 requires_human_review: true。
- 结尾附上：本结果仅用于信息辅助和人工审核，不作为临床诊断、处方或治疗决策依据。
